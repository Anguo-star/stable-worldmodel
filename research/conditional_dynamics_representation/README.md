# 世界模型如何从历史中学习条件动力学

本目录研究：模型能否从近期图像和动作识别当前环境的隐藏规律，并据此改变未来预测。我们使用ContextWorld区分条件预测能力、响应幅值和规划行为，研究哪些训练条件有助于获得这种能力。

## 当前认识

三模型六任务的实验显示，数据覆盖、模型和初始化共同影响上下文学习：

- 接触摩擦任务中，DINO-WM明显优于LeWM和PLDM；运动阻尼任务中，PLDM预训练初始化较强。
- 扩量可改善部分模型与任务，但不是所有失败任务的统一解法。
- 预训练初始化并非始终有益；DINO-WM的转换初始化还需与完整权重加载区别解释。
- 正确率、历史条件响应的幅值和原环境规划成功率可以不同步变化。

这些是每配置一个训练种子的Development观察，不是正式多种子Test结论，也未建立数据或模型缩放定律。完整数值、反例及适用范围见上述公开研究报告。

## 接下来的机制问题

优先研究接触摩擦与运动阻尼的反向模型优势。两项同属PushT环境，分别存在较强和较弱模型，适合比较同一任务的数据为何被不同训练方案学成不同能力。

先用已有检查点检验正确历史与交换历史下的候选动作排序和真实动作后果，再比较训练样本与Development的条件响应。只有干预特定环节并改变未见样本上的行为，才能进一步支持对数据覆盖、表示或训练目标的因果解释。

COJA是本目录探索的条件响应辅助训练方法。它可用于检验训练目标的作用；历史小规模实验或不同配方的改善，不自动证明当前完整训练配置的根因。

## 代码与证据

`scripts/`包含研究脚本，`tests/`包含对应检查，`artifacts/`在本地实验中保存运行结果。并非所有大型数据、检查点和原始输出均已公开；公开可获得的材料及复现限制以研究报告为准。

固定v3 benchmark不因后续研究改变。新增数据或方法结果应单独命名，并记录数据版本、权重身份、初始化、训练预算和评测划分。详细历史材料见[历史索引](HISTORY.md)。
