## 1. 论文定位

### 1.1 推荐标题

**ContextWorld：潜在世界模型中的历史条件可辨识性**

副标题：**从受控诊断到条件重叠联合对齐**

英文暂定：*ContextWorld: History-Conditioned Identifiability in Latent World Models*。

### 1.2 一句话主张

健康的隐变量边缘分布不保证模型学会“哪段历史对应哪个未来”；ContextWorld 用固定查询、只改变历史的干预式评测暴露这一缺口，COJA 则利用训练数据中的条件重叠直接对齐历史引起的预测响应，而且不增加部署参数或推理计算。

### 1.3 投稿方向

当前主线更接近 ICLR/ICML：核心贡献是学习问题、可识别性分析、受控 benchmark 和通用训练目标。若后续补齐视觉域规模、跨模型结果和规划视频，CVPR 也可考虑，但不应为了视觉叙事削弱条件可辨识性的理论主线。

### 1.4 贡献层级

主文只保留四项贡献：

1. **问题与 benchmark**：提出 ContextWorld，以 matched-history intervention 测量世界模型能否从历史识别回合级隐藏动力学。
2. **诊断与理论**：说明边缘非坍缩、历史可读和目标可分都不足以保证条件对应；给出无条件重叠时反事实响应不可识别的命题；并给出配对原生 MSE 的 center/response 分解，说明条件项存在但相对能量与梯度信噪比过低。
3. **方法**：提出 COJA，在共享可见条件的样本组内对齐预测响应与真实未来响应；不增加模型参数、模块和推理开销。
4. **实证**：比较多种世界模型目标，验证 COJA 对原本缺失的条件能力、隐藏动力学规划和标准环境保持的影响。

RC-COJA 暂定位为“滚动一致性扩展”，不与 COJA 并列成第二条主线。只有完整实验确认它是规划结论不可缺少的部分时，才进入主贡献；否则放入实验分析或附录。

## 2. 论文要回答的五个研究问题

正文结果不再按实验发生顺序组织，而按以下问题组织：

- **RQ1：现有世界模型在见过任务训练数据后，是否真正学会隐藏动力学 ICL？**
- **RQ2：全局非坍缩或更强边缘正则能否解决该问题？**
- **RQ3：COJA 是否改善同一查询下的历史条件响应，而不是只改变整体预测或数据曝光？**
- **RQ4：这种改善能否跨任务、跨模型目标，并转化为隐藏动力学规划收益，同时保留标准环境能力？**
- **RQ5：既然配对原生 MSE 精确包含条件响应项，native 为什么仍学不到——是相对能量、梯度信噪比
  还是查询覆盖不足？** 本稿只回答这个问题的**诊断一半**；"哪种训练分布能让原生目标自己产生条件
  压力"在本稿中保持开放，只以一条受限负边界出现（见 §7.6、§8）。
- **RQ6：有效性依赖哪些条件——条件监督的相对权重、查询覆盖、尺度校准与滚动监督？**

每个实验必须明确服务于一个研究问题；不再把"做过的实验"本身当作章节理由。RQ5 是全文的机制枢纽：
它把"边缘正则不够"的否定结论接到"条件项存在但相对能量/可见性过低"的机制解释，并据此说明为什么
需要显式条件监督；它同时约束 §5、§6 与 §7.6 的写法。数据分布一侧只写已获得的边界，不写成本稿的
正面结论。

## 3. 正文章节结构

### 1 引言

建立一个简单矛盾：模型拥有非坍缩 latent，也看过历史，却可能在相同查询下对不同动力学历史预测同一个未来。随后说明标准规划分数和线性 probe 为什么看不见该问题，引出 ContextWorld 与 COJA。最后用四条贡献收束。

### 2 相关工作

只分三类：潜在世界模型与 JEPA；表征非坍缩和动力学相关正则；历史条件系统辨识与 in-context world models。每类最后一句明确本文改变的变量：固定当前观测和动作，只干预历史。

### 3 问题定义：从边缘分布到条件联合关系

定义历史 $H$、当前观测 $Q$、查询动作 $A$、隐藏动力学 $M$ 和未来 $O^+$，研究
$p(O^+\mid H,Q,A)$。给出 matched-history estimand、条件响应及 gain/alignment/NRE。

本节只保留两个理论结论：

1. 仅依赖目标 latent 经验集合的边缘正则对样本对应置换不敏感，不能单独确定历史—未来对应。
2. 若同一可见条件下没有跨动力学重叠，反事实条件响应在非参数模型类中不可识别；精确配对是充分实现，不是唯一必要形式。

完整证明放附录。

### 4 ContextWorld benchmark

先说明构造原则，再列九项能力：相同 $Q,A$，不同历史揭示不同隐藏动力学。明确训练、Development、公开 Test 的用途，区分直接 ICL、隐藏动力学规划和标准环境保持。硬阈值作为协议诊断，不替代连续指标和置信区间。

### 5 现有目标为何失败

集中呈现四类证据：

- 边缘 latent 健康但条件响应接近零；
- 历史信息可被读出或目标未来可分，但 Predictor 没有形成方向、幅值正确的响应；
- 动态扩展历史和三步 native rollout 仍接近零响应，说明信息可用与多步误差都不自动形成条件辨识压力；
- LeWM 与 PLDM 的互补失败说明问题不是单一模型容量或单一正则强度。

六层诊断表缩为正文三层：历史信息、真实 future response、预测耦合与校准。采样覆盖和滚动一致性移到实验分析。

本节结尾必须放一段**根因桥接**，否则第 6 节会读成"换个 loss 就好了"。桥接的内容是：配对原生
MSE 精确分解为组中心项与响应项，正确—交换历史的损失差恰等于两者响应的内积，因此原生目标在
数学上**已经包含**条件响应项；失败不能写成"训练信号里没有这个量"。可支持的解释是该项相对能量
低、映射到参数后的梯度信噪比接近噪声边缘，因而被非条件更新主导。这是当前工作假说，其量化证据
来自单任务的冻结 batch 与 Development，正文必须写明这一边界，不得写成跨任务的普遍定理。桥接
同时确立两个下游方向：显式条件目标（第 6 节）与训练分布干预（§7.6、§8）。

### 6 COJA

先用一张图解释训练样本组，再给公式。正文突出三点：

1. 共享 $(Q,A)$ 的组打破“只看边缘集合”的置换歧义；
2. 响应项校准历史引起的方向和幅值，分配项保证对应关系；
3. COJA 只在训练时增加一次已有 Predictor 的计算，不改变保存模型和推理接口。

明确限制：当前实现需要条件重叠组或配对数据；隐藏动力学标签不输入模型，推理时不需要配对。按
§5 的桥接，COJA 应被写成**放大已有条件项的一种直接估计器**，而不是引入了原本缺失的新信号。

### 7 实验

#### 7.1 设置与比较原则

对每项方法效应使用同数据、同初始化、同预算的 native 与 `+COJA` 对照。公开原环境 checkpoint 只用于报告总部署差异，不能替代同数据对照。绝对保持量与 matched 方法增量分列，训练种子数与评测回合数分列。

#### 7.2 RQ1：baseline 失败矩阵

报告原始数据起点与组件训练后的结果，防止把“从未见过该能力”和“见过仍学不会”混为一谈。

#### 7.3 RQ2：边缘正则负对照

比较 LeWM/SIGReg、PLDM、VIS-WM/VISReg、DINO-WM；重点展示 target 不坍缩但 conditional response 仍失败的受控反例。

#### 7.4 RQ3：COJA 的跨任务效果

主要表格报告 matched native 与 COJA 的 future、history、switch、worst、gain、NRE 和 seed 数；Development 与 Test 分列。

#### 7.5 RQ4：跨模型可组合性与规划

先报告每个模型族内部的增量，不把不同模型的绝对分数混成方法归因。隐藏动力学规划与标准环境 CEM 分开呈现，并比较正确历史与交换历史。

#### 7.6 RQ5：原生条件项的定量诊断与训练分布可行性边界

先给负对照：sliding/expanding history 与 `K=3` native rollout 都没有把原生响应推离
"不随历史变化"的参照点，因此更长上下文与更多步预测误差都不是充分解释。再给定量诊断：paired
native MSE 的 center/response 分解、正确—交换历史 loss gap 的逐 query 分布与符号比例、条件
能量占比 $\rho_{\mathrm{cond}}$（物理表示与冻结 latent 两套）、条件梯度范数比与信噪比。既有
twin-sampler 作为"pair co-batching 单独无效"的负证据引用，不重复训练。

训练分布一侧只写**已获得的边界**，不写成本稿的正面臂。写作口径固定为：路线 B 的首个因果单元
`D2-v1`（Motion Damping + LeWM）已在 P1b 覆盖校准的结构门上有效失败并关闭——预先冻结的
`64 coverage cells × 3 action strata = 192` 个槽位只填满 `128`，`low_approach` 为 `0/64`——因此
它在任何训练开始前即终止，没有产生任何 native behavior 结果。这必须写成**结构门失败**，不能写成
"原生目标在该数据分布下学不到"，也不能推广为整条数据设计路线失败；它同样不反向抹除 P1a 在 base
forward/reverse 上的局部路由存在事实。数值与回执留 `EXPERIMENT_LOG_ZH.md` §7.2 与 claims ledger
C13/C14，本文件不复制。只改训练分布不构成 benchmark v2。

#### 7.7 RQ6：方法消融与边界

正确配对/打乱配对、权重阶梯、仅分配/仅响应、一步/滚动监督与训练计算开销。ActionDelay 长训练的
高分配、坏 NRE 必须作为 assignment 与 calibration 分离的案例，而不是二元成功/失败标签；配合
逐 checkpoint 的漂移起点定位，写成尺度误差与正交残差两个分量，不写成"纯尺度问题"。

### 8 讨论与局限

讨论条件重叠假设、训练期额外计算、连续动力学校准与长训练尺度漂移、短期—长程权衡、跨模型证据尚未补齐，以及 exact pairing 可由近邻、主动干预、数据重采样或结构假设替代的可能性。明确 COJA 是利用条件监督的一种直接估计器，不是唯一可能的最终方案。

本节还要把 §5 的根因桥接推到两条并行路线，并说明二者共享同一把评测尺子、不互相替代：路线 A 是
benchmark 与 COJA 的方法结论，路线 B 是"什么训练分布能让原生目标自己产生条件压力"的数据原则。
写法上，当前稿件的主线就是路线 A；路线 B 只以一段受限边界出现：`D2-v1` 在训练前的结构门上关闭，
因此本稿没有任何路线 B 的行为级结果，也不把 `D2` 写成正贡献。该边界只否定这一 action/geometry/
coverage 配方，不否定路线 B 本身；未来若重设计 generator 或 action family，必须作为独立预注册的
`D2-v2`，不是本稿的必做项，也不允许改写当前 revision。COJA 在任何一种分流下都仍是"该能力可被
诱导"的正对照，不因数据路线的任何结果被写成失败。

### 9 结论

回到一个结论：世界模型是否“没坍缩”与它是否“从历史识别动力学”是两个问题；后者需要直接约束条件关系。

## 6. 投稿前收束优先级

优先级由两条路线的分工决定，而不是由已跑过的实验决定。当前投稿主线是路线 A（benchmark + COJA）；
路线 B（数据分布原则）负责 RQ5 的正面一半，但其首个因果单元 `D2-v1` 已在训练前的结构门上关闭，
因此**路线 B 不在当前稿件的必做项内**，只作为一段受限负边界写入 §7.6 与 §8。已不存在跨路线的硬
执行约束；本稿的工作量应集中在整理与冻结既有证据，而不是继续开新的训练格。

### 必须完成

1. 冻结 benchmark v1 的自然评测协议与当前自然训练分布 `D0`，归档已有 `D0+native`、`D0+COJA`、expanding 与 rollout 的数据/代码/checkpoint 身份；公开 Test 保持锁定。
2. 只闭环并整理既有的同数据同预算 native 对照与 ActionDelay 短预算到 full-10 的校准轨迹；不追加 COJA+rollout、新 loss、COJA 变体、跨族完整训练或救援式训练数据调参。
3. 把路线 B 写成一条受限边界而非待办训练格：`D2-v1` 已在 P1b 结构门有效失败并关闭（`128/192`、`low_approach` `0/64`），未进入 sealed holdout 与 native 训练，故本稿不再要求补 `D1`/`D2` 的训练臂。任何 generator/action family 重设计只能作为独立预注册的 `D2-v2`，不属于当前稿件的必做项。
4. 最终模型只用 Development 选择，公开 Test 只报告一次；两者在表中分列。
5. 跨族主张的边界必须显式：`+COJA` 的跨族结论只能由实际任务结果支持，接口或梯度边界测试不能替代效果；未完成原生完整配方的模型族在表中写“—”，主张相应收窄到已有族内，而不是把补齐四族当作本稿的前置任务。
6. 报告已有的隐藏动力学规划和标准环境保持；后者必须与同数据 native 对照比较，公开 checkpoint 只作总效应参考。

## 8. 写作规则

- 每节开头先说要回答的问题，结尾只写本节支持的结论。
- 一个段落只保留一条因果链；先给现象，再给解释，最后给证据边界。
- 不用硬阈值替代效应量；报告点估计、区间和 seed 数。
- “未运行”与“失败”严格区分；Development 与 Test 严格区分；训练种子与评测回合严格区分；绝对保持量与 matched 方法增量严格区分。
- 不把隐藏标签、pair id 写成模型输入；同时直说训练依赖条件重叠组。
- 不写“证明 COJA 通用有效”，除非跨模型、跨任务和多 seed 矩阵完成；同样不写“COJA 失败”——分配改善与校准漂移必须分开陈述。
- 原生目标包含条件项这一点写成分解事实；它的能量/信噪比过低写成有证据支持的解释，不写成定理。
- GitHub 公式使用独立的 `$$ ... $$` 块，避免在表格中放复杂 LaTeX，也避免在一个公式块中混用自然语言。
